5つの約束
--
1．信頼を築く（自己）
信頼は、特別な場面で生まれるものではありません。日々の言葉と行動が誠実であること。その積み重ねが、確かな信頼を築きます。
2．一人ひとりに向き合う（他者）
教育は、それぞれの個性や背景を尊重することから始まります。愛情と思いやり、必要な厳しさと寛容さをもって、公平な教育に努めます。
3．チームで支え合う（組織）
心理的安全性を大切にし、一人ひとりが当事者意識を持って対話と助け合いを重ね、安全で安心して働ける組織をともにつくります。
4．学園とともに成長する（学園）
学園の成長は、目標を持ち、改善を重ねることで支えられます。受け継ぐべきものを大切にし、変化を恐れず、よりよい教育を追求します。
5．社会に貢献する（社会）
私たちは、学生・園児の成長に寄り添い、豊かな人間性を育むとともに、確かな専門性を備えた人材を輩出します。学園の知を社会に還元し、よりよい未来づくりに貢献します。

----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- 
1．信頼を築く
自己
--
素直
素直な姿勢を心がけ、指示・忠告・評価は前向きな気持ち・態度で受け止めます。
誠実
思いやりのある言葉と態度を大切にし、責任ある行動で周囲からの信頼に応えます。
プラス思考
何事も成長のチャンスと捉え、建設的な言動と発想で、より良い学びと環境を育みます。
--
鈴木学園ベーシック
1. 教え育むことに誇りと責任を持ち、真の教育者となるよう努めます。
2. 学生・園児にも、教職員同士でも必ず適切な言葉づかいをします。教育にとっての言葉の大切さを常に意識します。
3. 整理・整頓・清掃は教育の基本です。教職員が模範となって校内の清潔さを保ちます。
4. 教職員として、学生・園児の模範となる身だしなみと、振る舞いを心がけます。
5. 常に学生・園児の安全を最優先に考え、事故のない、安心できる環境をつくります。

----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- 
2．一人ひとりに向き合う
他者
--
愛
学生・園児を愛し、仕事を愛し、学園を愛する気持ちを持ちます。
思いやりと気配り
相手の立場を理解し、周囲の想いを意識した、優しさのある言動を心がけます。
多様性
多様な価値観、文化、背景、特性を尊重し、一人ひとりに公平で誠実に向き合います。
--
鈴木学園ベーシック
1. 学生・園児一人ひとりを大切にし、誰一人取り残さない教育を実践します。
2. 厳格さと寛容さを使い分け、メリハリのある教育を行います。
3. 学生・園児の情報に精通し、問題の早期発見と解決に最善を尽くします。
4. 学生・園児や保護者の声を真摯に受け止め、公平公正な解決を図ります。
5. 一人ひとりを尊重し、ハラスメントのない環境をつくります。

----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- 
3．チームで支え合う
組織
--
報連相
安心できる環境と信頼を築き、効率的に業務を進めるため、報連相とフィードバックを綿密に行います。
協働
一人ひとりが主体性を持って行動し、互いの立場や役割を理解しながら、力を合わせて業務に取り組みます。
ウェルビーイング
自他を大切にし、心や体に無理なく、安心して働き続けられる関係と環境をつくります。
--
鈴木学園ベーシック
1. コミュニケーションを大切にし、互いの仕事に関心を持ち、助け合える関係を築きます。
2. 年齢や経験にかかわらず自由闊達に意見を交わし、互いの考えから学び合います。
3. バランススコアカードを理解し、目標設定を行い、常に業務の改善に努めます。
4. 誇りと喜びを感じられる職場をつくり、よりよい教育と学校改革につなげます。
5. 平時のリスクマネジメントと、有事の危機管理を徹底し、各種マニュアルを遵守します。

----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- 
4．学園とともに成長する
学園
--
PDCA
明確な目標を持って教育に取り組み、その振り返りを改善につなげます。
継続と徹底
教育には教職員全体であたり、一つひとつを継続・徹底して実践します。
学び続ける
本質的な価値を大切にしながらも、急速に変化し続ける社会に向き合い、必要な知識と技能を学び続けます。
--
鈴木学園ベーシック
1. 各種評価の結果と他者のアドバイスを真摯に受け止め、プロフェッショナルとしての誇りを持ち、更なる教育能力向上に努めます。
2. 現状維持に満足することなく学校改革を推進します。
3. 新しい技術や仕組みを積極的に活用し、校務及び教育活動の質を高めます。
4. 常に広報活動を意識し、学生・園児募集に努めます。
5. 鈴木学園の資産を守るのは、教職員一人ひとりの役目です。常に経費意識を持ち、適正な節約に努めます。

----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- ----- 
5．社会に貢献する
社会
--
感謝
与えられた全ての物事に対し、「ありがとう」と感謝の気持ちを持ちます。
社会的存在
自らの仕事が地域・社会につながっていることを意識し、その一員として責任ある行動をとります。
産学官連携
企業や行政などと積極的に連携し、地域・社会の課題解決や新たな価値の創出に取り組みます。
--
鈴木学園ベーシック
1. 教育活動を通じて、地域に必要とされ、社会で生きる力を備えた人材を育てます。
2. 学園の知を生かし、地域の子育て・暮らし・産業を支え、社会に貢献します。
3. 地域・社会とのつながりや支えに感謝し、教育活動を行います。 
4. 環境問題に関心を持ち、身近な実践から持続可能な環境保全に取り組みます。
5. 地域・社会全般に関心を持ち、学外の人と積極的に交流して広い視野を身につけます。
